Lightweight visual perception

Turn a live camera or local video into structured object observations with an optional MediaPipe EfficientDet-Lite0 model. Detection is off by default. Media never leaves this browser.

Object detector

EfficientDet-Lite0 int8 · MediaPipe Tasks Vision · CPU delegate · no account, no paid API, no training.

Model not loaded

Enabling downloads the model (~4.60 MB) from the official MediaPipe catalog and loads the self-hosted MediaPipe Wasm runtime. The first load may take longer on mobile. If the worker or WebAssembly is unavailable, the preview remains usable with detection off. See docs/visual-perception-licenses.md for versions, sizes, sources, and deployment limits.

            What this experiment does and does not do

            • Uses a real browser-side object detector; no upload, paid API, training, or GPU requirement.
            • Worker inference keeps model compute off the UI thread. The page drops stale pending frames instead of growing an unbounded queue.
            • Completes detection at 2–5 FPS; adaptive mode combines a change probe with a periodic floor, so it does not rely only on frame diff.
            • Stores no whole video and no detection thumbnails. Sessions reset on source switch, video load/seek/restart, camera stop, and page exit.
            • Object tracking, OBJECT_APPEARED / MOVED / DISAPPEARED, and an Object State Index are future work; this page only emits stateless observations.
            • Reported metrics include load time/bytes, five-second input and detection FPS, submitted/completed requests, trigger reasons, queue and inference latency separately, foreground/background time, dropped work, and page long tasks/minute. No accuracy is reported without labels. Camera tracks are released on hidden/pagehide and are not restarted automatically.

            Read the repository's docs/visual-perception.md and docs/visual-perception-licenses.md for architecture and license/deployment notes.
